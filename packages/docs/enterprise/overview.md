# Sentinel Enterprise

Sentinel Open Source is built for individual developers and small teams to securely build applications and agentic workflows. **Sentinel Enterprise** scales this deterministic security platform for the needs of large organizations.

## Why Sentinel Enterprise?

When deploying Sentinel across a sprawling engineering organization with hundreds of repositories, managing configurations, triaging findings, and ensuring compliance becomes a bottleneck.

Sentinel Enterprise provides:
- **Centralized Dashboard:** A unified pane of glass to view security posture across all your repositories.
- **Role-Based Access Control (RBAC):** Granular permissions for developers, security engineers, and administrators.
- **Single Sign-On (SSO):** Seamless integration with Okta, Azure AD, and Google Workspace via SAML/OIDC.
- **Air-Gapped Deployment:** Run Sentinel entirely offline in highly secure, air-gapped environments.
- **Compliance Reporting:** Automated export of SOC2, HIPAA, and GDPR compliance documentation.
