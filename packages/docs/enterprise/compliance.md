# Security & Compliance

Sentinel is built to help you achieve and maintain compliance with major security frameworks. The platform not only scans your applications for vulnerabilities but also provides the reporting necessary for external audits.

## Supported Frameworks

Sentinel Enterprise maps its deterministic findings directly to controls within the following frameworks:
- **SOC 2 Type II:** Demonstrates continuous monitoring of code changes and active threat mitigation.
- **HIPAA:** Identifies potential leaks of Protected Health Information (PHI) via taint-tracking in CodeSentinel.
- **GDPR:** Flags insecure storage or transmission of Personally Identifiable Information (PII).
- **PCI-DSS:** Verifies that payment processing components are isolated and not vulnerable to DOM-based extraction.
- **OWASP Top 10:** All findings are automatically tagged with their corresponding OWASP category.

## Automated Compliance Reporting

Generating evidence for auditors is traditionally a manual, time-consuming process. Sentinel Enterprise automates this by providing a "Compliance Export" feature.

With one click, you can generate an auditor-ready PDF that includes:
- A summary of all scanned repositories over the audit period.
- Time-to-resolution metrics for Critical and High vulnerabilities.
- Proof of Code/Web/Recon correlation enforcing security gates in your CI/CD pipeline.
- An attestation of the deterministic rules currently enforced across the organization.
