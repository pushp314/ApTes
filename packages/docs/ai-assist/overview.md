# AI Assist Overview

Sentinel incorporates a **Local AI Assist** module (`AiReviewer`) to triage findings.

## Core Philosophy: Deterministic > AI
- **AI MUST NOT silently mutate deterministic findings.** The original finding generated by the static/dynamic engines is the immutable source of truth.
- The AI's evaluation is entirely confined to the `aiAssessment` property appended to the finding.
- The AI only evaluates findings marked with `LOW` or `MEDIUM` confidence (e.g., heuristic pattern matches). High-confidence findings skip AI evaluation to save budget.

## Local Only
Sentinel assumes security scans contain highly sensitive code and data. Therefore, the AI Assist module is hardcoded to interact with **Ollama** running locally. No data is sent to external APIs (like OpenAI or Anthropic) by default.
