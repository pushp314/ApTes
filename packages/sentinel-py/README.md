# Sentinel Python Security Toolkit

A standalone, zero-dependency Python 3 security assessment and penetration testing toolkit for modern web applications.

## Installation

```bash
# Via pip
pip install sentinel-security

# Or via pipx (zero-install runner)
pipx run sentinel-security dashboard
```

## Quick Start

```bash
# Launch interactive Mission Control Dashboard
sentinel-py dashboard

# Discover API endpoints
sentinel-py endpoints https://example.com

# Full vulnerability audit
sentinel-py audit https://example.com
```
